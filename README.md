# Fluent Enterprise UI

Fluent Enterprise UI is a React and Vite enterprise admin UI template built on Fluent UI, with a wrapped component layer.

## Stack

- React 19.3.1
- Vite 5.4.21
- TypeScript 5.9.3
- Fluent UI 9.75.0
- TanStack Router 1.170.46
- TanStack Query 5.105.0
- Zustand 5.0.16
- Vitest 2.1.9
- Playwright 1.64.1
- Knip 6.43.0
- pnpm 10.34.9
- ESLint 9.39.5
- Prettier 3.9.10
- Husky 9.1.7
- commitlint 19.8.1

## How to run

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
pnpm lint
pnpm typecheck
```
